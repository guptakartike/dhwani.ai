Audio queries stream directly from browser microphones into Sarvam Speech-to-Text. Transcribed queries pass through BGE multilingual local embedding models, ranked Qdrant vector retrieval, and a strict 2-tier guardrail gate before entering Groq grounded LLM generation.

⚙️ Component Contracts & Specifications

1. Speech-to-Text Service app/stt.py

Handles real-time streaming audio transcription using Sarvam STT engine (saaras:v3-realtime).

  • Input: Raw audio stream or base64 audio chunks via WebSocket / API
  • Output: TranscriptResult(text: str, is_final: bool, confidence: float)
  • Behavior: Partial & final transcripts; final transcript triggers retrieval pipeline automatically

2. Embedding Service app/embed.py

Generates normalized 384-dimensional dense vectors using local SentenceTransformers model.

  • Model: sentence-transformers/paraphrase-multilingual-MiniLM-L12-v2
  • Output: List[float] (384-dim vector embedding)
  • Zero Network Round-trip: Runs 100% locally on CPU / MPS Metal acceleration for sub-200ms budget

3. Retrieval Service app/retrieval.py

Executes multi-strategy vector search across 3 chunking strategy collections in Qdrant.

  • Strategies: Passage Chunking, Sentence Window Chunking, Semantic Chunking
  • Output: List[RetrievedChunk(text: str, score: float, strategy: str, source_id: str)]
  • Performance: Average vector search latency <39ms

4. Generation Service app/generate.py

Grounded answer generation using Groq Llama LLM models with strict context adherence.

  • Models: llama-3.3-70b-versatile, groq/compound-mini
  • Output: GenerationResult(answer: str, grounded: bool, sources: list[str])
  • Safety Prompt: Instructs model to answer strictly from provided context chunks

5. Guardrail Gate app/guardrails.py

Two-tier hard validation gate enforcing hallucination prevention.

  • Pre-generation Gate: Rejects query if top vector score < confidence threshold (0.45)
  • Post-generation Gate: Vetoes output if ungrounded, off-topic, or unsafe
  • Structured Refusal: Returns structured RefusalReason when triggered

6. Orchestration FastAPI Server app/main.py

FastAPI app wiring all services behind REST & WebSocket endpoints with automatic startup pre-warming.

  • Pre-warming Engine: Pre-loads vector DB & Metal shaders on startup for sub-200ms response
  • API Endpoints: POST /api/query, POST /api/stt/transcribe, GET /docs

📁 Dataset & Repository Architecture

Built on ai4bharat/MSMARCO-XI (Hindi subset). Passages are pre-segmented into passage, sentence window, and semantic chunking collections stored in Qdrant.
